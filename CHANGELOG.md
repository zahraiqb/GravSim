# Changelog
All notable changes follow [Keep a Changelog](https://keepachangelog.com) and [SemVer](https://semver.org).

## [0.1.0] - Unreleased
### Added
- C++20 N-body core: Euler, RK4, leapfrog (KDK), Yoshida-4, adaptive Dormand-Prince 5(4).
- 1PN Einstein-Infeld-Hoffmann relativistic corrections.
- Scenarios: Solar System (+ Pluto, Halley), Alpha Centauri, S2/Sgr A*, binary BH, Kepler, figure-eight, Pythagorean.
- Catch2 validation suite (Kepler, convergence order, symmetry, conservation laws, GR precession).
- CLI, WebAssembly build, Three.js viewer, CI and GitHub Pages deployment.
